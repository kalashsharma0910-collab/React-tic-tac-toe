# React Tic-Tac-Toe

A Tic-Tac-Toe game built with React and Vite. Play as X and O, track turns, and start a rematch after the game ends.

## Features

- Two-player gameplay
- Player name editing
- Win and draw detection
- Turn history
- Rematch option

## Built With

- React
- Vite
- JavaScript
- CSS
